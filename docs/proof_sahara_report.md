# Earth feature grid — Phase 1 report

Generated by `python -m backend.pipeline.build_earth_features` on 2026-11-15 00:15 UTC.

## Grid

- **0.05° lon/lat** grid, 1200 × 600 cells, north-to-south rows, cell centres.
- Bounds: lon -20 → 40, lat 10 → 40.
- Tiling: 10° tiles with a 1° halo, reprojected to a local 2.00 km azimuthal-equidistant grid; features computed in km windows by the shared registry; ocean cells filled with the nearest land elevation before filtering; sampled back with area averaging.
- Climate: WorldClim 2.1 2.5 arc-minute (~4.6 km) area-averaged to the search grid; this is a slight coarsening, not added detail.
- Land mask: WorldClim ocean nodata; a cell is land when its valid fraction is at least 0.5. Every feature is NaN over ocean.

## Polar coverage notes

- The configured grid does not reach 66.5°S, so Antarctic coverage is not exercised by this run.
- The configured grid does not reach 66.5°N, so Arctic coverage is not exercised by this run.
- At high latitude a search-grid cell is only a fraction of a kilometre wide in longitude; terrain features come from the local working grid, so adjacent polar cells repeat the same terrain sample. This is documented rather than hidden.

## Limits

- WorldClim is **air temperature**, not surface skin temperature, and its Antarctic values are weakly constrained.
- ETOPO includes bathymetry; the WorldClim land mask removes ocean cells, and ocean cells are filled with the nearest land elevation before filtering so coastal relief is not inflated by the shelf.
- The lon/lat grid is not equal-area. At high latitudes, longitude cells are much narrower than at the equator; area weighting is reported above.
- Earth cannot reproduce reduced gravity, vacuum or the thin Martian atmosphere, or the radiation environment.
- Moon and Mars temperatures are literature values, added in Phase 2; no synthetic temperature raster is used.
